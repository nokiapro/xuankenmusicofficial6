Khi có prefix, bài hát & user lưu dưới prefix/songs, prefix/users... Settings luôn ở root settings.

Migrate: copy songs + users từ root sang prefix (không xóa root). Cần Firebase Rules cho phép đọc/ghi path prefix trước. Xem hướng dẫn bên dưới.

Hướng dẫn Firebase Rules cho prefix 
{
  "rules": {
    "settings": {
      ".read": true,
      ".write": "auth != null"
    },
    "songs": {
      ".read": true,
      ".write": "auth != null"
    },
    "users": {
      ".read": true,
      ".write": true
    },
    "prices": {
      ".read": true,
      ".write": "auth != null"
    },
    "music6": {
      "songs": { ".read": true, ".write": "auth != null" },
      "users": { ".read": true, ".write": true },
      "prices": { ".read": true, ".write": "auth != null" }
    }
  }
}

Vào Firebase Console → project music6-dfd59 → Realtime Database → tab Rules → dán → Publish. Sau đó bấm Migrate root → prefix (đã đăng nhập Admin).

Đăng nhập bằng Firebase Auth · project music6-dfd59

Xuất / nhập danh sách bài hát

Xuất toàn bộ list bài (JSON) để backup hoặc thêm link mới. Nhập file JSON để ghi đè / bổ sung bài lên Firebase.

Khi nhập: bài trùng ID sẽ được cập nhật, bài mới sẽ được thêm. Không xóa bài không có trong file.
